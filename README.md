# 鼻鼻的AI魔法廚房

繁體中文 3D 互動式料理應用。使用 Three.js 0.170.0、Vanilla JavaScript ES Modules 與 LocalStorage。

支援 **雙模式智慧推薦**：
1. **Google Gemini 3.5 Flash AI 連線生成模式**：輸入 Gemini API Key 即可開啟真正的 LLM 創意料理即時研發。
2. **本地精選食譜庫模擬推薦模式**：無 API Key 時自動平滑備援，使用內建 32 道經典實體食譜庫。

---

## 🌟 Gemini 3.5 Flash 智慧生成特色

- **合情合理，絕不天馬行空**：內建專業主廚與食安系統提示詞（System Prompt），嚴格規範料理必須符合大眾口味、烹飪科學與日常家常常理，嚴禁發明草莓炒牛肉、香蕉炒飯等荒謬黑暗料理。
- **嚴格遵守設備限制**：使用者若只選微波爐，產出的食譜保證 100% 只用微波爐；若只選電鍋，保證完全以電鍋蒸煮完成。
- **時間與食材精準掌控**：依指定分鐘數與人數設計，優先運用冰箱現有食材，將需購買的缺料控制在最少且常見的基礎調味料。
- **安全與隱私保證**：API Key 僅保存在使用者的瀏覽器本地端（LocalStorage），不經過任何第三方中介伺服器，直接與 Google 官方端點連線。
- **收藏與離線檢視**：AI 生成的客製料理可直接加入「我的收藏」，即使重新整理或離線也能隨時回顧完整步驟與份量。

## 開始使用

1. **挑選食材**：點擊 3D 冰箱或「打開冰箱」，勾選或文字輸入手邊的食材。
2. **烹飪方式**：點擊水槽或「料理方式」，複選家中現有的設備（快炒、燉煮、微波爐、電鍋、烤箱、油炸、清蒸）。
3. **客製偏好**：設定用餐人數（1~5人）、希望時間、口味偏好與飲食排除/過敏原。
4. **API Key 設定**：
   - 點擊右上角「🔑 設定 API Key」或瓦斯爐頁面中的「輸入 Gemini API Key」。
   - 貼上從 Google AI Studio 取得的 API Key。
   - 系統即切換為 **Gemini 3.5 Flash 智慧生成模式**。
   - 若未輸入 Key，系統將使用內建 32 道經典食譜庫進行推薦。
5. **開火推薦**：點擊「✨ Gemini AI 創意料理」或「✨ 開始料理推薦」，觀賞小熊廚師的備料、切菜、烹飪與上菜 3D 動畫！

## 本機預覽

- **雙擊直接使用**：直接雙擊 `index.html`（使用已打包之 `js/direct-app.js`）。
- **一鍵啟動**：雙擊 `啟動廚房.cmd`，自動啟動預覽並開啟瀏覽器。
- **Node.js 預覽伺服器**：在專案資料夾執行 `node preview.mjs`，瀏覽 `http://127.0.0.1:4173`。

## 檔案架構

- `js/kitchen3d.js`：程式化 3D 迷你廚房、家具模型、Raycaster 互動射線、相機視角控制、冰箱門與小熊烹飪動畫。
- `js/main.js`、`js/ui.js`：UI 面板切換、表單驗證、API Key 彈窗互動、食譜詳情渲染與收藏清單管理。
- `js/ai-service.js`：Google Gemini 3.5 Flash API 串接、System Prompt 規範、JSON 結構化解析與多層備援機制。
- `js/recipe-data.js`：內建 32 道經典實體食譜庫，含份量、料理步驟與過敏原提醒。
- `js/recipe-engine.js`：條件篩選、食材別名正規化與加權推薦演算法。
- `js/storage.js`：LocalStorage 容錯持久儲存（食材、設定、API Key、AI 生成食譜、收藏清單）。
- `build-direct.mjs`：打包 ES Modules 為雙擊可用單檔的建置腳本。

執行單元測試：
```bash
node --test tests/engine.test.js
```
涵蓋：
- 32 道內建食譜完整性與唯一定義
- 烹飪方式與時間硬性篩選
- 排除食材與過敏原過濾
- 格式別名與正規化處理
- 無金鑰保護與未授權拒絕呼叫
- Gemini Prompt 合理烹飪約束與排除檢查
- Gemini API 回傳 JSON 解析與食材對應
- 未設定金鑰時平滑備援至本地推薦
